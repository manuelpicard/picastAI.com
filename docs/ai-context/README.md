## Beim Start einer neuen KI-Sitzung

1. Lies zuerst das Repository-`README.md` und `ORGANIZATION.md`.
2. Lies die aktuelle [`KI-Übergabe vom 1. November 2026`](handoff-2026-11-01.md) für den letzten Code-/Teststand und die offenen nächsten Schritte.
3. Prüfe Branch, Remote und Commit und hole aktuelle Änderungen aus GitHub, bevor du an Dateien arbeitest.
4. Lies [`Kunibert-Kanon.md`](../Kunibert-Kanon.md) für Figuren und Storyregeln sowie den aktuellen Erzählcode/Prompts.
5. Lies [`conversation-context-2026-10-02-to-2026-10-14.md`](conversation-context-2026-10-02-to-2026-10-14.md) für ältere Nutzerentscheidungen und Verlauf.
6. Nutze [`Produktentwurf-Ritter-Kunibert-2026-10-02.md`](Produktentwurf-Ritter-Kunibert-2026-10-02.md) nur als historischen Stand. Domain-, Hardware- und Plattformannahmen können inzwischen veraltet oder durch das aktuelle README ersetzt sein.

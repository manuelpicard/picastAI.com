Einen Moment …

Handy mit Kunibert verbinden

  1. Halte am Gerät beide Tasten 5 Sekunden lang gedrückt.
  2. Kunibert sagt einen Code mit sechs Ziffern. Der Code gilt 10 Minuten.
  3. Gib den Code hier ein.

Im Test sagt das Gerät den Code noch nicht. Dann bekommst du den Code vom Betreiber.

So geht es vielleicht schneller:

  1. Verbinde dein Handy mit dem WLAN, in dem auch Kunibert ist. Schalte dafür die mobilen Daten aus.
  2. Lass Kunibert einen neuen Code sagen.
  3. Gib den neuen Code hier ein.

Das hilft nicht immer. Zum Beispiel nicht, wenn Handy und Gerät auf verschiedenen Wegen ins Internet gehen.

Einwilligung

Mit deiner Einwilligung darf Kunibert auf diesem Gerät zuhören, antworten und Geschichten erzählen. Ohne Einwilligung sagt Kunibert nur einen festen Hinweis.
